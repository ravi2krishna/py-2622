        -> Positional Arguments

    -> Arbitrary Positional Arguments 

        -> Arbitrary Means Random / Unknown 

        -> In Python, Arbitrary Positional Arguments Allows A Function To Accept 
        Unknown Number Of Positional Arguments

        -> This Is Achieved By Placing an * symbol before parameter name in Function Definition 

        -> The parameter will collect all the positional Arguments into Tuple Data Structure

    -> Arbitrary Keyword Arguments    

        -> Arbitrary means unknown or random 

        -> In Python, arbitrary keyword arguments allow a function to accept 
        a unknown number of Keyword arguments. 

        -> This is achieved by placing an asterisk (**) before a parameter name 
        in the function definition.

        -> The parameter will collect all the positional Arguments into Dictionary Data Structure

    -> Packages 

        -> A Folder With "Multiple Modules" (Multiple Python Files)

        -> A Package contains special file named as __init__.py 

        -> __init__.py can be empty, but generally we keep 
        startup information or startup data configuration

        -> In Order To Use Package, use the name of the folder 

        -> Syntax 

            from package_name import module 

            from package_name.module_name import function_name 



    -> File Management With Python 

        -> open() function

                -> The built-in open() function in Python is used to open a file on your system 
                and return a corresponding file object, serving as the foundation for 
                all file input/output (I/O) operations.

        -> Syntax - 1

                file = open("file_path","mode")

                file = open("file.txt","r")  

                -> NOTE: Here we need to "explicitly close" files 
                after operations are performed

        
        -> Syntax - 2 (Recommended)

                with open("file_path","mode") as alias_name:
                    statements 
                
                with open("file.txt","r") as file_data:
                    statements 

                -> NOTE: Here we don't need to "explicitly close" files 
                after operations are performed, as it is implicitly closed (auto close)

Class - 18
============

        -> For Fixed Data Sets, we can use "reader" functionality from csv module

            -> students.csv file

        -> For Changing Data Sets, we can use DictReader functionality from csv module

            -> sample.csv file (structure is changed)

    
        -> The main components of the csv module are:
            
            -> csv.reader(file): Reads CSV data and returns each row as a list of strings.
        
            -> csv.writer(file): Writes data to a CSV file from lists.
            
            -> csv.DictReader(file): Reads data by mapping the information to a dictionary, 
            using the first row as field names (keys).
            
            -> csv.DictWriter(file, fieldnames): Writes data from a list of dictionaries 
            to a CSV file, using the dictionary keys as column headers.

Class - 19
============

    -> Python has provided "json" modules to work with JSON Data / Files 

    -> Python's built-in json module allows you to serialize (convert Python objects into JSON) and 
    deserialize (parse JSON back into Python objects).


    -> JSON operations 

        -> json.dump() - Serializes a Python object to a JSON-formatted file (writes to a file pointer).

        -> json.load()	Deserializes a JSON-formatted file to a Python object (reads from a file pointer).

        -> json.dumps()	Serializes a Python object to a JSON-formatted string ("dump string").

        -> json.loads()	Deserializes a JSON-formatted string to a Python object ("load string").
