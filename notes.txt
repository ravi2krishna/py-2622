Class - 15
============

    -> Based On Arguments Passed To Functions, We Got Five Types 

        -> Positional Arguments 

        -> Keyword Arguments 

        -> Default Arguments 

        -> Arbitrary Positional Arguments 

        -> Arbitrary Keyword Arguments    

    
    -> Arbitrary Positional Arguments 

        -> Arbitrary Means Random / Unknown 

        -> In Python, Arbitrary Positional Arguments Allows A Function To Accept 
        Unknown Number Of Positional Arguments

        -> This Is Achieved By Placing an * symbol before parameter name in Function Definition 

        -> The parameter will collect all the positional Arguments into Tuple Data Structure

        
Class - 16
============

    -> Arbitrary Keyword Arguments    

        -> Arbitrary means unknown or random 

        -> In Python, arbitrary keyword arguments allow a function to accept 
        a unknown number of Keyword arguments. 

        -> This is achieved by placing an asterisk (**) before a parameter name 
        in the function definition.

        -> The parameter will collect all the positional Arguments into Dictionary Data Structure


    -> Reusability

        -> A Block Of Code - Functions (call with function_name)

        -> A File Of Code - Modules (call with file_name)

        -> A Folder Of Code - Packages (call with folder_name)

    
    -> From Learning Perspective 

        -> Content -> File -> Folder [ Function -> Module -> Package]

    -> NOTE: In Real World, Packages Contain Modules and Modules Contain Functions 

        -> Folder -> File -> Content [ Package -> Module -> Function]


    -> Modules 

        -> A Module is a "Simple Python File" which contains python definitions 

        -> Syntax 

            -> import module (imports complete module i.e loads all the functionalities)

            -> from module import specific_functionality  (imports only what you need) # Recommended

        
        -> Inbuilt Modules 

                -> Provided as part of Standard Python Library 

                -> math module provides access to common mathematical functions and constants

                -> Python Inbuilt Modules - https://docs.python.org/3/py-modindex.html

            
        -> User Defined Modules 

                -> Created By Developers For Custom Requirements 
                
                -> NOTE: Here module name is nothing but file name 

                -> Requirement: User/Customer needs arithmetic operations and profile related information



        -> External Modules 

                -> Provided By 3rd Party Vendors 

                    -> https://pypi.org/
